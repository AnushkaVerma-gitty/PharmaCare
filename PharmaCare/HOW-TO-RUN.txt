=====================================================
   PharmaCare - Pharmacy Management System
=====================================================

HOW TO RUN
----------
1. Right-click the zip > Extract All.
2. Open the "PharmaCare" folder.
3. Double-click  START-PharmaCare.bat
4. Your browser opens by itself at http://localhost:8080

FIRST TIME ONLY: it builds the app (and downloads Java if your PC
does not have it). This takes about 3-5 minutes and needs internet.
After that, it starts in about 15 seconds.

HOW TO STOP
-----------
Close the black window.

IF WINDOWS SHOWS "Windows protected your PC"
--------------------------------------------
Click "More info" > "Run anyway".

IF WINDOWS FIREWALL ASKS ABOUT JAVA
-----------------------------------
Click "Allow". (The app only runs on your own computer.)

RUN FROM VS CODE
----------------
1. VS Code > File > Open Folder > select the "PharmaCare" folder.
2. Press  Ctrl + Shift + B   (this runs START-PharmaCare.bat)

CHANGED THE CODE?
-----------------
Double-click  REBUILD-and-START.bat

YOUR DATA
---------
Saved in the "data" folder. To start fresh: close the app and
delete the "data" folder.
